# Holiday Chasers Post Helper (Chrome extension)

Install: chrome://extensions → Developer mode → Load unpacked → pick this `extension` folder.

Use: click the extension icon, choose a post, press "Use this post". It opens the Facebook page
(@holidaychasersie). Open the composer, press the gold "Fill post" button, check, then press Post yourself.
It never posts on its own. Posts come from https://holidaychasers.ie/social/posts.json (rebuilt by the scan).
